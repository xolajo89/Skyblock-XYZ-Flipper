# XYZ FLIPPER 0.9.213

Портативный Windows-клиент XYZ FLIPPER, версия **0.9.213**. После запуска откроется панель управления в браузере, а приложение останется работать в системном трее рядом с часами.

## Как запустить и пользоваться

1. Скачайте `XYZ-FLIPPER-0.9.213-portable-x64.exe` из раздела [GitHub Releases](https://github.com/xolajo89/Skyblock-XYZ-Flipper/releases) и запустите его.
2. Используйте открытую в браузере панель для управления экземплярами и настройками.
3. Чтобы снова открыть панель, нажмите значок XYZ FLIPPER в системном трее. Если значок скрыт, раскройте область скрытых значков стрелкой `^` рядом с часами.
4. В контекстном меню значка доступны **Open Web Dashboard** для панели в браузере, **Open Window** для окна приложения и **Exit XYZ FLIPPER** для полного завершения работы.

Закрытие вкладки панели не завершает приложение: оно продолжает работать в трее. Для остановки выберите **Exit XYZ FLIPPER**.

## Файлы проекта

Исходный код и стандартные пресеты находятся в этом репозитории. Портативный EXE размером около 120,7 МиБ хранится отдельно от Git-файлов; его нужно прикрепить к релизу как release asset.

В репозитории находятся исходники, стандартные настройки и встроенные пресеты. Личные профили пользователя и runtime-данные аккаунтов в него не включены. Проверка отслеживаемых файлов не обнаружила токенов, паролей или сессионных секретов. Единственное непустое поле, похожее на имя аккаунта, — стандартное значение `xyz` в шаблоне; пароли в шаблонах пустые.
