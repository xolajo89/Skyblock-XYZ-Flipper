# XYZ FLIPPER 0.9.213

Portable Windows client for XYZ FLIPPER, version **0.9.213**. When launched, it opens the control dashboard in your browser and continues running in the system tray near the clock.

## Getting started

1. Download `XYZ-FLIPPER-0.9.213-portable-x64.exe` from [GitHub Releases](https://github.com/xolajo89/Skyblock-XYZ-Flipper/releases), then run it.
2. Use the browser dashboard to manage instances and settings.
3. To reopen the dashboard, click the XYZ FLIPPER icon in the system tray. If the icon is hidden, open the hidden icons menu using the `^` arrow near the clock.
4. Right-click the tray icon to choose **Open Web Dashboard** (browser), **Open Window** (app window), or **Exit XYZ FLIPPER** (fully quit the application).

Closing the dashboard browser tab does not stop the application; it keeps running in the tray. Choose **Exit XYZ FLIPPER** to shut it down.

## Project files

This repository contains the source code, default settings, and built-in presets. The portable executable is about 120.7 MiB and is kept out of regular Git commits; attach it to a GitHub Release as a release asset.
