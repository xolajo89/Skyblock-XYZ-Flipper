# XYZ FLIPPER 0.9.213

Portable Windows client for managing XYZ FLIPPER instances.
Hypixel bazaar macro.

## Usage

Run `XYZ-FLIPPER-0.9.213-portable-x64.exe`. The dashboard opens in your browser, and the app stays active in the system tray. Click the tray icon to reopen the dashboard. Right-click it to open the app window or exit XYZ FLIPPER.
